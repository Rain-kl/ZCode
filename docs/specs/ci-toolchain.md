# 发布构建工具链

发布构建使用固定版本的 Node.js 和 pnpm，按锁文件安装工作区依赖。依赖版本覆盖与补丁清单由工作区配置维护，安装、补丁检查和许可证记录使用同一份配置。

Canary 并行运行构建、静态检查与全部测试，构建通过后即可发布；正式版构建和测试通过后发布。测试结果保留真实成功或失败状态，并汇总到 Actions 摘要。桌面端与 Server 按各自平台生成产物并发布。

Android 构建使用 Java 21，由 SDK 初始化步骤显式安装 Platform Tools、Android 36.1 平台和 36.1.0 Build Tools，随后执行测试、签名构建与产物上传。

验收：全新环境和重复安装均可完成；依赖覆盖和补丁保持生效；Server 与桌面端构建使用相同安装配置；正式版测试门禁与 Canary 发布条件生效。
