# Android 远程控制

首次启动输入 HTTPS 后端地址，连接后保存地址。再次启动直接打开该后端的远控设备列表；后端地址在首次保存后固定。远控登录、设备选择与会话由网页提供。

```text
首次启动 → 输入后端地址 → 保存地址 → 打开远控网页
再次启动 → 读取地址 → 打开远控网页
返回键 → 网页后退；无历史时退出应用
```

普通启动进入设备列表；扫码或明确的设备链接可进入指定连接。网络失败时提供重试。正式版与开发版各自随 GitHub Release 提供可安装 APK，使用固定签名保证后续版本可覆盖安装。

应用图标沿用桌面客户端图标。连接后以完整页面展示网页，保留系统安全区。
