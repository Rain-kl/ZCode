# 区分工具硬边界与既有 profile 审批模式

Task3b 权限交集修复限制的是父可用工具、静态 deny 与网络限制，不能将其描述为全新审批模式上限。
独立规范审查以真实 runtime 和隔离临时文件验证：普通 profile 缺省模式继承父 plan，不执行 Write；
显式 bypassPermissions 按既有模式策略执行 Write。测试最终清除临时文件。此行为与旧解析一致，
不是此次工具越权修复引入的授权变化，不追加模式实现改动。

设计文档明确上述边界；内置 Explore 沿已有策略，guarded 对派生 yolo 的约束继续由既有
inheritPermissionMode 提供。避免用宽泛的“父没有权限”掩盖当前真实的可配置审批策略。

此提交仅澄清设计与验证边界，不新增工具、权限、兼容、持久化或配置字段。
