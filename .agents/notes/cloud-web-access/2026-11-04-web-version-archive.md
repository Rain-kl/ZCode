# 网页版本资源归档

- 归属：R2 持有已发布清单及内容寻址资源；ASSETS 持有当前构建。Worker 精确选择完整版本，并校验文件大小和完整性。
- 发布顺序：构建 → 校验文件 → 上传缺失资源 → 原子创建版本清单 → 部署。相同版本不同内容拒绝发布，上传失败不会产生可用清单。
- 上游接线：Web 构建入口与既有版本解析器；其余逻辑留在独立 fork 脚本与 Relay 包。普通本地 Web 构建仍使用现有 Vite 参数与资源路径。
